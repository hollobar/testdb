### 확인한 것
- Python 쪽 시험을 마쳤습니다.
  - 가상 데이터 500명 집계와 학생정보 500/500명 연결
  - 암호화한 HTML 안에 이름·전화번호가 평문으로 없음
  - 승인된 직원은 잠금이 풀리고, 틀린 비밀번호·퇴사자·거절자는 풀리지 않음
- `실행.bat`, `직원관리.bat`을 실행해 정상으로 끝나는 것을 확인했습니다.

### 아직 확인하지 못한 것
- 브라우저 화면(JavaScript)은 직접 보지 못했습니다. 다음에 브라우저로 열어 아래 항목을 확인해야 합니다.
  - [ ] 로그인 화면이 나오고 `demo` / `demo1234!`로 들어가지는가
  - [ ] 표, 검색, 필터, 막대그래프가 제대로 움직이는가
  - [ ] 아이 이름을 누르면 개인정보 창이 뜨는가 (담당자용)
  - [ ] 공유용 화면에서는 이름을 눌러도 개인정보가 뜨지 않는가
  - [ ] [회원가입]을 누르면 신청서 파일이 내려받아지는가
  - [ ] 그 신청서를 승인하고 화면을 다시 만든 뒤, 새 아이디로 로그인되는가
  - [ ] 30분 동안 조작하지 않으면 다시 잠기는가, [나가기] 버튼이 작동하는가

## 3. 파일 구성

| 파일 | 역할 |
|---|---|
| `수강관리.py` | 본 프로그램. CSV 읽기 → 집계 → 암호화 → HTML 두 개 만들기 |
| `직원관리.py` | 직원 계정 관리 (목록, 승인, 거절, 퇴사) |
| `화면틀.html` | 화면 디자인과 동작(로그인·회원가입·목록·개인정보 창). 프로그램이 이 틀에 데이터를 넣는다 |
| `실행.bat` | 더블클릭하면 화면을 만든다. `수강기록.csv`가 있으면 그것, 없으면 가상 데이터를 쓴다 |
| `직원관리.bat` | 직원 신청·승인 현황을 보고 명령(`승인 아이디`, `거절 아이디`, `퇴사 아이디`)을 입력한다. 끝나면 화면을 다시 만든다 |
| `가상데이터.csv`, `가상학생정보.csv` | 시험용 가짜 데이터. 이름은 `학생001`·`보호자001`, 학교는 `A초등학교`, 주소는 `가상시 가동 12`처럼 번호·기호만 쓴다 (2026-10-10 GitHub 공유를 위해 실제 이름·지역명을 뺐다) |
| `결과/수강현황.html` | 담당자용 화면 (개인정보 포함) |
| `결과/수강현황_공유용.html` | 공유용 화면 (개인정보 없음) |
| `직원/` | 가입신청·승인·거절·퇴사 폴더와 `직원계정_양식.csv`. **공유 금지** |
| `__pycache__/` | Python이 자동으로 만드는 폴더. 신경 쓰지 않아도 된다 |

### 실제 데이터를 넣을 때
- **수강 기록**: `수강기록.csv`로 저장한다. 열은 `학생번호, 이름, 학년, 반, 수업명, 날짜`이고, 수업 한 번이 한 줄이다. 학생번호와 날짜는 없어도 된다.
- **학생정보**: `학생정보.csv`로 저장한다. 열은 `학생번호, 이름, 학년, 반, 보호자 이름, 보호자 연락처, 주소, …`이고, 아이 한 명이 한 줄이다. 나머지 열은 개인정보 창에 그대로 나온다.
- **열 이름이 다를 때**: `수강관리.py` 위쪽 `COLUMNS`에 시트의 열 이름을 추가한다.
- **필요한 패키지**: Python 패키지 `cryptography`가 있어야 한다. 이 PC에는 2026-10-10에 설치했다.

## 4. 정해진 사항과 가정

- **연결 기준**: 수강 기록과 학생정보는 학생번호로 먼저 연결한다. 학생번호가 없으면 이름·학년·반이 모두 같은 아이로 연결한다. 그런 아이가 둘 이상이면 연결하지 않는다(다른 아이 정보가 뜨는 것을 막기 위해).
- **반 배정 (가정)**: 가상 데이터는 1~2학년 씨앗반, 3~4학년 새싹반, 5~6학년 열매반으로 만들었다. 실제 기준은 아직 확인하지 않았다.
- **직원 아이디**: 영문 소문자·숫자 3~20자이고 대소문자를 구분하지 않는다. 비밀번호는 8자 이상이다.
- **변경 반영**: 승인·퇴사는 화면을 다시 만들어야 반영된다. 이미 나눠 준 예전 화면은 예전 계정으로 계속 열린다.
