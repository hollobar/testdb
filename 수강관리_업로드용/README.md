# 창의교육 수강관리 (연습용)

구글 시트의 수강 기록으로 **아이별 수강 현황 화면**을 만드는 프로그램입니다.
직원만 아이디·비밀번호로 열어 볼 수 있습니다.

> 이 저장소의 아이·보호자·주소·전화번호는 모두 **지어낸 가상 데이터**입니다.
> 실제 데이터(`수강기록.csv`, `학생정보.csv`)와 직원 계정(`직원/` 아래 폴더)은 `.gitignore`로 막아 두었으니 올리지 마세요.

## 연습 1 — 화면 열어 보기 (설치 필요 없음)

1. `결과/수강현황.html`을 내려받아 크롬이나 엣지로 엽니다.
2. 아이디 `demo`, 비밀번호 `demo1234!`로 들어갑니다.
3. 아래를 해 봅니다.
   - 이름을 검색하고, 반과 수업으로 걸러 봅니다.
   - 오른쪽 수업별 막대를 누릅니다.
   - 표의 줄을 눌러 수업 날짜를 봅니다.
   - 아이 이름을 눌러 개인정보 창을 엽니다.
4. `결과/수강현황_공유용.html`도 열어, 개인정보가 보이지 않는지 비교해 봅니다.

## 연습 2 — 회원가입과 승인

1. 로그인 화면에서 **[회원가입]**을 누르고 신청서를 만듭니다. `가입신청_아이디.json` 파일이 내려받아집니다.
2. 관리자 역할을 해 봅니다.
   - 그 파일을 `직원/가입신청/` 폴더에 넣습니다.
   - `직원관리.bat`을 실행하고 `승인 아이디`를 입력합니다.
3. 엔터를 눌러 화면을 다시 만들고, 새 아이디로 로그인해 봅니다.
4. `퇴사 아이디`로 계정을 막고 다시 만든 화면에서 로그인이 안 되는지 확인합니다.

연습 2부터는 PC에 Python이 있어야 합니다. 아래 "준비"를 먼저 해 주세요.

## 준비 (연습 2부터)

1. [Python](https://www.python.org/downloads/) 3.10 이상을 설치합니다. 설치할 때 "Add python.exe to PATH"에 체크합니다.
2. 명령 프롬프트에서 아래를 한 번 실행합니다.
   ```
   python -m pip install cryptography
   ```
3. `실행.bat`을 더블클릭하면 가상 데이터로 화면이 새로 만들어집니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `수강관리.py` | 본 프로그램. CSV를 읽고 집계한 뒤 암호화해 HTML을 만든다 |
| `직원관리.py` | 직원 계정 관리 (승인·거절·퇴사) |
| `화면틀.html` | 화면 디자인과 동작 |
| `실행.bat` | 화면 만들기 (`수강기록.csv`가 없으면 가상 데이터를 쓴다) |
| `직원관리.bat` | 가입 신청 승인 등 |
| `가상데이터.csv`, `가상학생정보.csv` | 연습용 가상 데이터 |
| `결과/` | 만들어진 화면 |
| `작업현황.md` | 개발 진행 기록 |

## 실제로 쓸 때 형식

- **`수강기록.csv`**: `학생번호, 이름, 학년, 반, 수업명, 날짜`. 수업 한 번이 한 줄입니다.
- **`학생정보.csv`**: `학생번호, 이름, 학년, 반, 보호자 이름, 보호자 연락처, 주소, …`. 아이 한 명이 한 줄입니다.

실제 데이터로 만든 화면에는 가상 데이터용 `demo` 계정이 들어가지 않습니다. 반드시 직원 계정을 승인한 뒤에 만들어야 합니다.
