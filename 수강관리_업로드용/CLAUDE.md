# 수강관리 프로젝트

- 작업을 시작하기 전에 `작업현황.md`를 읽고, 지난 작업 내용과 다음 할 일을 파악한다.
- 작업을 마치면 `작업현황.md`의 "지금까지 한 일", "아직 확인하지 못한 것", "다음에 할 일"을 고친다.
- 아이·보호자 개인정보를 다룬다. 실제 데이터(`수강기록.csv`, `학생정보.csv`)와 `직원/` 폴더 내용을 화면 밖이나 외부 서비스로 보내지 않는다.
- 시험은 가상 데이터(`python 수강관리.py --sample --no-open`)로 한다. 시험용 계정을 실제 `직원/` 폴더에 남기지 않는다.
